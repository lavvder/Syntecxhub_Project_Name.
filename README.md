Syntecxhub is an educational technology and software development company that offers virtual training and internship programs for students and professionals. 

PROJECT 1
Student Performance Analysis Dashboard (Power BI)

📌 Project Overview
This project analyzes student performance data using Power BI to understand how different factors — such as gender, ethnicity, parental education, and test preparation — affect student scores in Math, Reading, and Writing.

This was completed as Internship Project - Task 1.
🎯 Task Objectives
Load and preprocess student dataset (marks, attendance, etc.)
Analyze subject-wise and overall performance trends
Identify factors affecting performance (study hours, attendance, parental background, etc.)
Compare performance across different groups/classes
Visualize data using charts (bar, pie, donut)
Generate insights for improving academic results

🛠 What I Did
1. Loaded and Cleaned the Dataset
Imported student records (scores, gender, ethnicity, parental education, test preparation status) into Power BI and prepared the data for analysis.

2. Calculated Key Performance Metrics
Built summary cards showing:

3. Analyzed Performance Across Different Groups
Compared average scores across ethnic groups (Group A–E)
Compared performance between male and female students
Compared scores based on parental education level (Bachelor's, Some College, High School, Associate's Degree, etc.)
Compared scores based on test preparation status (completed vs. none)

4. Identified Performance Patterns:
Cross-analyzed ethnicity and parental education together to see their combined effect on scores
Highlighted the Top 5 performing students based on Math, Writing, and Reading scores

5. Built Interactive Visualizations
📊 Bar charts for group-wise score comparison
🍩 Donut/pie charts for gender and test preparation distribution
📈 Horizontal bar chart for parental education impact

This allows anyone viewing the dashboard to explore the data dynamically.

💡 Key Insights:
Students whose parents have a Bachelor's degree tend to score higher on average.
Score percentages are fairly balanced between male and female students.
Ethnic Group C had the highest average score percentage, while Group D had the lowest.
Most students in this dataset had not completed any test preparation course.
